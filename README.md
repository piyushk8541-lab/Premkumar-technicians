# Prem Kumar Technicians

A premium, mobile-first, zero-build website for **Prem Kumar Technicians**, an electronic appliance repair and electrical service business in Darbhanga, Bihar.

## Included

- Single-file semantic HTML5 website with Tailwind CSS via CDN
- Alpine.js filters, mobile navigation, and review modal
- Vanilla JavaScript booking and review forms that open WhatsApp
- Phone, email, Google Maps and WhatsApp conversion links
- AOS scroll animations, animated counters, responsive marquee and floating actions
- LocalBusiness JSON-LD, canonical URL, Open Graph tags, robots.txt and sitemap.xml
- All 18 requested services, transparent Zone A / Zone B pricing, local service area content, and developer credit section

## GitHub Pages deployment

1. Push the repository to GitHub.
2. In **Settings → Pages**, choose **Deploy from a branch**.
3. Select the required branch and `/ (root)` folder, then save.
4. If a custom domain is purchased, update the canonical URL, Open Graph URL, JSON-LD URLs, sitemap, and add the domain in GitHub Pages settings.
5. Replace the photo and social image placeholders noted in `index.html`.

The site does not require npm, Node.js, a build command, a database, or a server. The booking and review forms are intentionally static-site friendly: they format the visitor's details and open WhatsApp so Prem Kumar can receive and respond to the lead.

## Important launch checks

- Replace the placeholder portfolio URL (`https://example.com`) in the developer credit section.
- Add Prem Kumar's consented photo at `assets/images/prem-kumar.jpg` and an `assets/images/og-prem-kumar.jpg` social preview image.
- Replace the illustrative review content with customer-approved reviews before public launch, and update the JSON-LD rating/count to match verifiable information.
- Connect and verify the Google Business Profile for the exact shop location.
